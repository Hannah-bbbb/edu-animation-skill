# 故事式英语启蒙动画 Skill

将已有英语启蒙视频工程中的制作经验整理为可复用的智能体技能：从教学目标和小故事出发，生成或复用角色动作，处理透明帧、配音与字幕，最终交付可审查的视频。

**智能体执行入口：[SKILL.md](SKILL.md)。** 本页面向仓库使用者，介绍用途与使用方法；具体制作规则在技能指南和专题文档中维护。

## 可以做什么

- 根据内容计划设计独立小故事，保持相邻知识点的衔接。
- 用角色参考图和提示词调用火山方舟 Seedance，保存可追溯的动作原片。
- 用 Python、OpenCV 和 FFmpeg 将绿幕 MP4 转成透明 PNG 序列，保留原动作位移并校准角色大小。
- 在 Godot 4 中用 AnimatedSprite2D 测试循环、单次回待机和末帧保持，也可打包图集交给现有视频渲染器。
- 组织逐句配音、实际发声驱动的口型、中文释义、关键词强调、BGM和音效。
- 按工作流检查、归档成片并维护后续制作进度。

仓库包含指南、文本模板和辅助工具。完整课程渲染器、角色素材、声音参考、模型和视频由目标制作工程提供；复制本仓库不等于已经拥有一键成片系统。

## 如何使用

可以将仓库作为普通工作副本保存，直接让智能体读取本地指南，无须先安装技能。例如：

> 请先阅读 `/你的目录/edu-animation-skill/SKILL.md`，再检查 `/你的制作工程` 的计划、工作流和素材。根据当前进度制作下一集；先复用已有素材，缺口再按指南处理。

也可以只指定其中一环：

> 请阅读这个 skill，只将指定目录中的绿幕 MP4 转成 Godot 素材，并校准不同动作的角色大小。本次不制作课程视频。

把示例路径换成实际路径。技能工作副本与制作工程分开存放：配方、参考素材、生成任务状态、透明帧和成片都写入制作工程，保持本仓库干净。

## 运行条件与验证

按需要准备依赖，不必为了阅读指南安装全部环境：

| 使用环节 | 条件 |
| --- | --- |
| 方舟任务工具 | Python 3.10+；实际调用需要相应模型权限和环境变量 `ARK_API_KEY` |
| 透明帧与图集 | Python 3.10+、NumPy、OpenCV、FFmpeg和ffprobe |
| 动作播放测试 | Godot 4 |
| 可选本地配音桥 | Apple Silicon Mac、兼容的MLX Audio环境和已准备的Qwen3-TTS Base模型，详见声音指南 |
| 完整课程渲染 | 目标工程已有渲染、混音和交付链路，详见制作与交付指南 |

已具备依赖时，在仓库根目录执行离线测试：

```bash
FFMPEG=/实际路径/ffmpeg GODOT=/实际路径/godot python -B scripts/self_test.py
```

将可执行文件路径和Python解释器换成实际环境。`GODOT`可省略，此时明确跳过引擎测试；测试使用临时合成数据与模拟API，不调用付费模型，也不下载模型。具体测试范围见维护文档。技术测试不替代角色审美、发音和成片的人工审核。

## 持续迭代

发现问题时，先定位提示词、原片、抠像、校准、配音或时间轴中的实际原因，再修改对应指南或工具。README保持简短导览，制作规则集中维护；修改接口时同步示例与测试，通过Git提交追踪变化。

仓库只保存技能所需的文本和代码，不提交视频、图片、录音、字体、模型、缓存或密钥。当前工作副本未安装到本机技能目录。

# 内容规划：连贯且每条独立

先读取项目的宏观计划和当前内容组。默认续作推进同一方向尚缺的相邻知识，达到基础覆盖边界后再换方向；不要因追求新鲜感，每集跳换知识领域。场景、人物任务和道具可以变化。用户指定主题时优先，保留被中断组的接续点。

## 最小单集设计

在目标工程保存：年龄与基础、2–3个紧密相关的新知识点、1个主要表达、人物想做什么、什么发生了变化、怎样尝试、结果、片尾回顾。已有 schema 时使用其字段，不直接塞入尚未实现的字段。

默认约4–8岁、美式英语；通常50–80秒，包含回顾，一般不超过90秒。它们是可调整的项目默认值，不是学习效果保证。按实际语音测量时长；超量时删减或拆成相邻故事，不拉长静默、加快发音或机械凑时长。

例如教 six / seven / eight：露营想数星星，云移开后逐个发现新星星，数清后许愿。数量词改变人物看到的结果；云的移动有故事作用。背景生成时不画固定星点，可数星星单独绘制，避免背景的“装饰星星”让数量失真。

每条都提供必要人物、场景与词义线索，不要求看过前集。片尾回顾只复现本集重点，用实物/动作、放大英文、必要中文和清楚的读音示范；不在片尾引入新知识，不默认安排专门复习集。

## 长期方向参考

项目没有既定计划时可按以下能力组织，具体词句和故事逐集确定：

1. 听懂身边的人、物、动作、基础颜色、大小、1–10数量。
2. 表达需要、喜欢、拥有、能力和感受，进行简短问答。
3. 组合颜色、大小、数量、位置等线索描述和寻找。
4. 合作完成准备、出行、购物等任务，表达先后和简单原因。
5. 理解和复述事件链，逐步讲述经历、预测和人物感受。
6. 用已有英语观察自然、比较信息、解释选择和创编故事。

这不是考试级别、固定分集排期或必须顺序观看的课程。阅读、声音游戏和拼读按观众基础融入；不凭做完几条视频判断升阶段。

## 知识与画面一致

- 数量：可见对象数、字幕、编号和读音一致；“想要八个”和“已经有八个”明确区分。回顾用同类同尺寸对象，不能放大一个代表多个。
- 大小：同一画面留有参照，物体尺度稳定；不能用两张各自填满画面的图比较。
- 动作：台词说“正在变大”时动作仍持续；说“停”时实际停止；揭示先于“看见了”的台词。
- 场景：避免每条复用同一背景和相同构图元素；按情节复用角色，适当更换地点、时间和道具。

状态只需记录当前组、覆盖范围、尚缺、下一增量和结束边界。内容已制作、技术验证、用户批准、孩子掌握是四种不同事实；没有学习观察时写未收集。

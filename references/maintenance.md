# 维护这个 skill

当前版本0.1.0，提炼自已有英语启蒙工程的可复用方法。skill负责跨项目方法和小工具；目标工程工作流负责当地规范与命令，计划负责内容方向，状态负责实际进度。两边同步已验证经验，避免复制整个项目历史成为第二套状态文档。

## 允许进入仓库的内容

`README.md`、`SKILL.md`、界面元数据、专题参考、纯文本模板、必要辅助脚本与离线测试。README供人了解用途和查找入口，具体制作规则由SKILL及专题文档维护，避免重复。不要加入视频、PNG/图集、录音、背景/字体、模型、运行缓存、用户绝对路径、Key、签名下载链接、当前制作日志或完整课程工程。本仓库不是素材仓库，也不是自动安装包。

所有使用输出写到目标工程或隔离临时目录，不写回本skill。默认不安装到`~/.codex/skills`等自动发现路径。修改时直接维护这个Git工作副本，不额外复制多个“最终版”。

## 迭代方法

收到反馈先定位真实失败：提示词、实际原片、matte、固定校准、时间轴、语音生成、混音、字幕或交付。只有得到实际证据或用户明确偏好时，才修改对应参考/脚本；不能将一个场景的偶发失败扩展成所有任务的强制复杂流程。

如果改变接口或默认规则，同步调用示例和相关测试，修改frontmatter版本，检查所有相对链接和脚本`--help`。Git提交说明问题、行为变化与验证方式即可，不另建重复更新日记。新模型参数来自官方文档/实际请求，明确何者是项目限制、何者是供应商能力。

## 检查方式

```bash
# 在已具备NumPy/OpenCV和FFmpeg的环境中；全程合成小图形、mock云端，不收费。
FFMPEG="$FFMPEG" GODOT="$GODOT" python -B scripts/self_test.py
```

测试产物放临时目录，检查防重复提交/规格拒绝、参考漂移、去绿保留白色身体、原位移、16FPS、PNG透明、图集布局和输出保护。`FFMPEG`是已有可执行文件；`GODOT`可选，提供时在临时工程中验证真实loop/return_idle/hold，否则该项明确跳过。`-B`避免在skill内写Python缓存。Qwen桥如只验证导入/参数，必须明确未完成新环境的真实合成；不要为验证本skill随意下载模型或产生付费任务。

可以使用skill-creator的`quick_validate.py`做frontmatter检查；没有该工具时核对name/description、命名、相对链接和未完成占位内容。模板中的显式待填值可以保留，运行工具必须在付费前拒绝未填模板。

发布前逐项审查`git diff --cached`和完整跟踪文件清单：全部文本、无素材/凭证/本机路径、无运行数据；不依赖.gitignore代替检查。只推到用户指定远端，不强推、不修改远端权限，不将技能推送视为安装授权。

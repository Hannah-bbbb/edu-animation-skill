# 素材 → 故事视频 → 可追溯交付

## 选择现有制作链路

Godot用于素材播放/测试不意味着所有成片必须改用Godot。原工程使用React/Remotion编排已核对的Godot同源透明帧，复用课程、配音、字幕、音轨与QC。已有渲染器可按同一时间轴契约接入；新工程先实现最小单场景，不复制完整旧工程或重建复杂编辑器。

新场景只增加确有教学意义的事件函数和图形。不要每集复制播放器、配音器或字幕系统；分开保存内容数据、素材登记、动作时间函数和画面组件。

## 最小数据契约

下列是设计契约，不是随包即有的课程schema。采用项目现有字段：

| 内容 | 必须可确定的信息 |
| --- | --- |
| 课程 | 唯一ID、阶段/内容组、目标词句、独立故事摘要、时长预算 |
| 台词 | 稳定ID、speaker、speech、caption、captionZh、声音版本、音频路径和实测时长 |
| 时间轴 | 每句start/end、发声区间、pause、跨句事件区间、音效cue起止 |
| 角色动作 | 动作名、源FPS/帧数、播放方式、固定layout、闭嘴检查事实、认可版本 |
| 场景 | 背景引用、对象状态、连续运动、当前知识点强调 |
| 交付 | 来源哈希、运行ID、视频/QC/字幕/审核记录；批准绑定具体版本 |

同一事件用独立于beat的连续时钟：`eventTime = currentTime - eventStart`，跨台词不能清零。故事的状态结果在后续句保留；需要“完成后说”的台词在事件结束后开始。时长依赖真实配音，不用硬编码一秒动画抢在对白前结束。

## 构图、字幕和动作

默认竖版1080×1920、30 FPS；背景、人物、教学道具、字幕分层。保留画面安全区，字幕不能遮脸/关键道具。英文在上，较小中文在下，选择可爱但清楚的本地字体并保存许可证，验证中文字形覆盖。

关键词可从普通字号1.25倍和独立强调色开始，实际检验换行和行高。背景复杂时加浅/深底衬、描边等；在手机大小看整句可读性，不能只检查色值。每类目标词保持稳定强调方式。字幕来自脚本和实际时间轴，不烧进生成背景。

优先真实帧动画、少量闭嘴反应、连续道具和环境变化；动作与故事因果相连。不用频繁闪切或无关抖动凑“丰富”。人物可以安静倾听，不要求复杂肢体和走位。运动采用连续缓动，数量/大小/方向在转场和回顾中保持正确。

若使用纯程序图形教学，在故事、回顾和缩略道具之间复用同一绘制函数，防止“前面六个，片尾七个”或对象比例变化。背景内多余的教学对象也计入孩子实际看见的数量。

## 渲染与检查

1. 完成素材、配音、schema/模板扩展和相关测试；冻结episode、主题、素材/声线、渲染代码与实际依赖版本。
2. 制作低清**有声**预览，正常连续播放，查看关键事件、口型、字幕和回顾；必要时半速看切换、轮廓和脚底。
3. 修正原始来源后新建运行，不改已保存的快照哈希。配音来源未变时复用缓存。
4. 生成高清，检查容器/编码/尺寸/FPS/帧数/时长、整片解码、声音实际存在、剪切/响度/留白，抽查首中末、事件交界和片尾。
5. 形成可审查视频、封面、双语SRT、简介和必要追溯资料。素材/声线认可不等于课程批准；人审仍标pending，除非用户明确批准具体版本。

代码测试只能证明覆盖的行为，contact sheet不能证明流畅，静音文件有波形不能证明读音。技术检查、助手看图/播放、人工完整听审分别记录。缺轨/纯配乐等负例应能被声音检查拒绝。

## 归档和清理

在目标工程约定纯视频目录，例如 `视频成片/L1_听懂身边的世界/EP020_中文内容名.mp4`，只放推荐高清副本；原始运行输出、历史失败/QC、包和缓存各有稳定目录。索引将推荐版本指向源运行与真实审核状态。复制前后核对哈希，不凭修改时间猜最新。

收尾保存：本集教学覆盖、当前组尚缺/下一增量、素材新增与限制、实际代码/测试证据、具体版本人审状态。只更新已有工作流/计划/状态的对应事实，不重复建日记和多个权威指南。

仅删确定可再生且无需追溯的临时抽帧、诊断WAV、预览网页和无用日志；不按“大”或“旧”直接清理原片、参考图/录音、生成任务ID/配方、已交付视频、历史失败证据、有效缓存。先核对引用/文件清单，删除后验证保留输出哈希，必要时留简短清理收据。Git忽略的媒体另行备份；提交代码、配置、提示词和必要来源记录。

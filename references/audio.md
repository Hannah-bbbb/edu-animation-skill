# 声线、逐句配音、口型和声床

## 先固定角色声线

沿用项目已认可的声线版本，保留参考原录音、实际原台词、模型/运行依赖版本、生成参数和用户选择记录。选定声线不代表未来台词都读对。参考原台词必须与参考音频吻合，不能填准备生成的新句子。

童真可爱优先用温暖、柔和、自然的语气，不靠过高音调、尖锐高频或夸张鼻音。新声线先独立试音；用户只要声音时不合成视频。更换参考建立新版本，不覆盖旧参考和缓存。

Qwen的Base用于参考声音克隆，VoiceDesign用于描述式设计声音，两者不能混为一个接口。先设计参考、试听选定，再由Base克隆新台词的流程见[官方项目](https://github.com/QwenLM/Qwen3-TTS#voice-design-then-clone)。本包的MLX桥只接Base，不承诺提供情绪提示词或rate调速。

## 本包可选本地桥

`scripts/qwen_voice.py`要求Apple Silicon Mac、已准备的本地Qwen3-TTS Base模型和MLX Audio环境。原工程已使用Python3.12 + `mlx-audio==0.5.8`；这是已用组合，不宣称所有平台或新版本兼容。模型可参考[MLX社区Base转换](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-Base-4bit)，需要显式下载完整权重与speech tokenizer并固定revision；脚本不自动下载、安装或升级。

```bash
"$VOICE_PYTHON" "$SKILL_DIR/scripts/qwen_voice.py" \
  --model-dir "$MODEL_DIR" \
  --reference-audio voices/rabbit-v2/reference.wav \
  --reference-text-file voices/rabbit-v2/reference.txt \
  --text-file dialogue/b021.txt --output audio/b021.wav
```

输出是模型原采样率的mono PCM16 WAV，推理设置离线；已有输出拒绝覆盖。该脚本没有完整课程缓存、裁静音或混音，目标工程应复用原实现或按下述契约接入。其他平台用已有TTS/录音provider，不为使用本skill强行换MLX。

## 逐句生成与时间轴

每条台词有稳定ID、speaker、英文speech、英文caption和独立中文captionZh。按句保存音频；片尾重复词分别生成/播放，例如两次fish是两个片段，不能依赖一次合成 `Fish. Fish.` 的标点获得标准读音。相同词同声线可复用已认可缓存。

缓存键覆盖台词、声线ID/版本、模型revision或字节、参考音频/原文、推理程序及依赖版本、采样参数与后处理。只修改一条台词时重合成该条，其余哈希保持。生成器变了却沿用旧缓存会让声线和追溯失真。

生成后读取实际时长。只裁去首尾多余空白，保留约0.12秒缓冲作为原项目经验起点；句内停顿与尾辅音不能被阈值切掉。片尾两次读音之间可从0.25秒编排停顿试起，检查音频自带留白后的真实间隔。原项目人声最长残差静默上限0.9秒；其他工程需明确自身预算，不能看到BGM不断就声称对白连贯。

音量偏弱、词尾含混或读音错误时只重生成问题句并复核完整接句。改变标点仅是自然表达尝试，不能承诺纠音；降低音调、EQ、提音量或ASR转写正确都不能替代听审。保留原候选与所选版本依据。

## 实际发声驱动口型

在**对白单独音轨**上提取语音活动区间，而非从混有音乐的成片波形取阈值。可用短窗能量/VAD和适度边界平滑，实际核对词头、词尾和句中静音，不能在每个零交叉都切动作。

调度优先级：有声窗口→说话循环；静音且有经核对闭嘴反应→该反应；其余→闭嘴待机/倾听。语音存在时不让闭嘴反应覆盖；听者的张嘴欢呼不适合充当静默倾听。记录图集与动作版本，按实际渲染时间检查双方交替和回顾词。

切换时共用固定脚底和比例，循环时间连续；短反应按原速选可用片段，不把4秒动作压到0.5秒。不把反向行走当正向走；思考/指向的反向收回也要实际检查。这只是发声区间同步，并非音素口型。

## BGM、环境和音效

用有明确来源/许可的器乐BGM和对应事件的音效；可用代码合成简单短铃、柔和风声等并记录参数/随机种子。雨声对应下雨、轮声随车停，音效不要跨过事件结束。低龄内容避免刺耳长雷声。

人声优先；从低音量声床开始，以实际混音判断遮蔽。保留对白stem与声床stem供检查。检查峰值、剪切、逐句响度变化、实测对白留白与BGM相对响度；不要用一条统一dB值保证所有声音可懂。成片采样率/声道统一，例如48kHz双声道AAC，源录音仍保留。

混音QC如需重建参考，使用实际渲染器的裁切、延迟、增益和舍入方式。曾遇到长视频FFmpeg延迟float32舍入造成一个sample差异；应以固定版本的实际实现和脉冲/缺轨反例验证，而不是调松阈值或搜索移位来“通过”。具体旧工程位置见[适配文档](project-adapter.md)。

听审至少核对目标词的元音、重音、词尾、单词示范与句中读法、漏词及情绪；无听审能力时标明待听审，交付具体台词和音频。
